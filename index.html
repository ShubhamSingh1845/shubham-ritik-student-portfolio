Weather Pattern Analysis and Prediction System

Group project by Shubham Kumar and Ritik Singh. All project work was done by both of us.

A Streamlit dashboard that explores weather observations with data cleaning, visual analysis, K-Means clustering and cautious machine-learning estimates. It makes data quality visible and evaluates models on observations that occur later in time than their training data.

View GitHub repository ↗

Project objectives

  • Load the provided weather CSV or a user-uploaded dataset.
  • Retrieve historical observations from the free Open-Meteo Archive API (default location Patna, Bihar; searchable for any Indian city).
  • Identify missing values, duplicates, invalid measurements and IQR outliers.
  • Visualize measurements, correlations and clusters.
  • Compare a seasonal-naive baseline with a Random Forest on a chronological holdout.
  • Export outputs as CSV downloads.

Tools & technologies

🐍 Python🐼 Pandas🔢 NumPy🤖 Scikit-learn📊 Plotly🌐 Requests🖥️ Streamlit🌦️ Open-Meteo API🐙 Git/GitHub

Data mining techniques

  • Preprocessing: duplicate removal, invalid-value flagging, median imputation of predictors only, IQR outlier detection.
  • Descriptive statistics, correlation analysis, monthly summaries.
  • K-Means clustering with scaled features (exploratory, not forecasts).
  • Random Forest regression with lag and cyclical calendar features.
  • Seasonal-naive 7-day lag baseline.
  • Chronological split (latest 20% held out) to avoid data leakage.
  • Evaluation with MAE and RMSE.

A few things we can explain

Viva Q&A.

What is data mining?

Data mining is the process of examining data to discover patterns, relationships, and useful information.

Why split chronologically?

For time-based data, training on earlier observations and testing on later ones better reflects how a model would be used in practice.

What is data leakage?

Data leakage happens when information unavailable at prediction time influences model training or evaluation, making results misleading.

What are MAE and RMSE?

They measure average prediction error. MAE averages absolute errors; RMSE squares errors before averaging and taking the square root, so larger errors count more.

Why scale data for K-Means?

K-Means uses distances. Scaling helps features with large numeric ranges from dominating the distance calculation.

What is the IQR outlier rule?

The interquartile range is Q3 − Q1. Values below Q1 − 1.5 × IQR or above Q3 + 1.5 × IQR are flagged as potential outliers.

Is Open-Meteo Archive a live forecast?

No. The Archive API provides historical weather data, not a live forecast.

What is a lag feature?

A lag feature is a previous observation used as an input, such as a measurement from seven days earlier.
